# Changes

One folder per intent. `clock-instant/` is a complete worked example — read it first.

Each folder holds the seven files of the path, written in order, plus the append-only `record.md`. `python3 tools/check.py changes/<slug>` is the gate; it is mechanical, and what it cannot decide is listed in [../framework/RULES.md](../framework/RULES.md) rather than guessed at.
